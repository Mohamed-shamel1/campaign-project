# Cosmetics WhatsApp Campaign Manager | مدير حملات واتساب لصيدليات التجميل

تطبيق ويب عصري ومتطور لإدارة الحملات التسويقية عبر واتساب، مصمم خصيصاً لصيدليات التجميل والعناية بالبشرة. يتيح استيراد جهات الاتصال من ملفات Odoo (CSV أو Excel)، والتحقق من صحة أرقام الهواتف المصرية (+20) وكشف التكرار، وصياغة الرسائل مع إرفاق الصور الترويجية، ومعاينتها بواجهة واتساب تفاعلية واقعية، وتجهيز حزم البيانات للإرسال عبر WAPilot API v2.

---

## 🚀 المميزات الرئيسية (Key Capabilities)

1. **استيراد ملفات جهات الاتصال (CSV & XLSX)**:
   - معالجة وفحص محلي كامل للملفات داخل المتصفح بأمان دون رفعها لخوادم وسيطة.
   - كشف تلقائي لأعمدة الهاتف واسم العميل مع إمكانية التحديد اليدوي للأعمدة.
   - دعم كامل للأرقام بصيغ Excel العلمية (Scientific / Float) والأرقام المنقوص منها الصفر المبدئي.
   - تحويل الأرقام المكتوبة بالأرقام العربية والمشرقية (٠١٢٣٤٥٦٧٨٩) إلى أرقام معيارية.

2. **محرك التحقق من أرقام الهواتف المصرية (Egyptian Phone Validation)**:
   - التحقق من شبكات المحمول المصرية الأربعة: فودافون (010)، إتصالات (011)، أورنج (012)، وي (015).
   - توحيد الأرقام وفق معيار E.164 الدولي (`+201xxxxxxxxx`).
   - كشف الأرقام المكررة داخل الملف مع توضيح سبب الاستبعاد.
   - كشف الخطوط الأرضية الثابتة (02, 03) واستبعادها لعدم ملاءمتها لرسائل واتساب.
   - جدول تصفية وتدقيق متقدم يتيح مراجعة السجلات (الصالحة، غير الصالحة، المكررة) بالكامل مع أسباب الرفض بالتفصيل.

3. **صياغة الرسائل الترويجية وإرفاق الوسائط**:
   - محرر نصي تفاعلي يدعم فواصل الأسطر، التنسيقات (مثل `*نص عريض*`) وتخصيص الرسائل `{اسم_العميل}`.
   - عداد مباشر للحروف والأسطر.
   - نماذج رسائل تسويقية جاهزة ومقترحة لصيدليات ومراكز العناية والتجميل.
   - إمكانية رفع صورة ترويجية للعرض (JPG, PNG, WebP) ومعاينتها واستبدالها أو حذفها.

4. **محاكي واتساب التفاعلي (Realistic WhatsApp Simulator)**:
   - شاشة هاتف محاكاة بتفاصيل واتساب الحقيقية (شريط الحالة، علامة الحساب التجاري الموثق، التاريخ، خلفية المحادثة، فقاعة الرسالة، الصورة المرفقة، والوقت مع مؤشرات القراءة).
   - عرض فوري وحي أثناء كتابة الرسالة أو رفع الوسائط.

5. **هيكل برمجي مهيأ للربط السحابي (WAPilot API v2 via Vercel Functions)**:
   - طبقة خدمات نظيفة (`wapilotService.ts`) تفصل واجهة المستخدم عن منطق الربط.
   - جاهزية كاملة لمعاينة حزمة الـ JSON Payload التي سيتم إرسالها إلى نقطة النهاية السحابية.
   - الحفاظ على سرية مفاتيح الربط البرمجي (عدم كشف الـ Tokens في واجهة المتصفح).
   - عرض حالة صادقة للربط والإحصائيات دون أي ادعاءات وهمية لعمليات الإرسال.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **React 18 & TypeScript**: بنية برمجية معيارية عالية الدقة ونظافة الكود.
- **Vite 5**: سرعة في البناء والتطوير مع تقسيم الحزم (Rollup Chunk Splitting).
- **Tailwind CSS 3**: نظام تصميم SaaS راقٍ بألوان مخصصة لصيدليات التجميل (Plum / Rose / Champagne / Slate) ودعم كامل لاتجاه RTL العربي.
- **React Router 6**: توجيه مسارات سلس ومنظم.
- **Lucide React**: أيقونات عصرية موحدة خالية من الإيموجي التقليدي.
- **SheetJS (xlsx)**: قراءة واستخراج البيانات من ملفات Excel و CSV محلياً.

## ☁️ النشر على Vercel (Deployment on Vercel)

المشروع مهيأ بالكامل للنشر الفوري على منصة **Vercel** بنقرة واحدة أو عبر Vercel CLI:

1. **إعداد مسارات التوجيه (vercel.json):**
   - تم ضبط إعادة التوجيه التلقائي (SPA Rewrites) لجميع مسارات React Router لتعمل بسلاسة عند عمل Refresh بدون أخطاء 404.
   - تم توجيه طلبات `/api/*` تلقائياً إلى دوال **Vercel Serverless Functions**.

2. **متغيرات البيئة المطلوبة (Environment Variables):**
   قم بإضافة المتغيرات التالية في لوحة تحكم Vercel (`Project Settings -> Environment Variables`):
   - `WAPILOT_API_KEY`: مفتاح الـ API السري الخاص ببوابة WAPilot v2 (يظل سرياً على الخادم).
   - `WAPILOT_INSTANCE_ID`: معرف مثيل واتساب المخصص لصيدليتك.
   - `WAPILOT_API_URL`: (اختياري) الافتراضي `https://api.wapilot.net/v2`.

3. **النشر عبر Vercel CLI أو GitHub:**
   - بمجرد ربط المستودع بحساب Vercel وعمل Push، سيتعرف Vercel تلقائياً على إعدادات `vite` ويقوم بالبناء والنشر في ثوانٍ معدودة.
